## MVP範囲の改訂

2026-09-04の要件更新により、対応する項目をMenuAllから手動で「非表示→表示」「表示→非表示」へ実際に切り替える機能をMVPへ追加した。従来の「項目の位置変更・項目別の表示／非表示管理はMVP対象外」という記述は、この手動切り替えに限って撤回する。

任意位置への並べ替え、永続ルール、条件別の自動切り替え、プロファイルは引き続き対象外である。元メニューを開く操作と表示切り替えはUI上も処理上も分離する。

製品起動では実`CGEventMenuBarVisibilityChanger`を構成し、可否未評価時はトグルを無効化する。イベント列はCommandを保持したmouseDown→複数mouseDragged→mouseUpとし、対象と境界を同一のWindowServerスナップショットで一意に照合したうえで、解決済みの所有PIDだけへ送信する。Ice等の競合とMenuAll本体・境界の安全な左右順は操作直前にも再評価する。

表示管理コードへのAIレビューでは、起動直後の境界展開、画面外項目の展開前拒否、Window ID再利用、更新との競合、未検証rollback、固定システム項目、失敗後の再操作などを指摘・修正した。Unit、Releaseビルド、静的解析は修正後に再実行済みである。実項目を動かすE2Eは利用者のヘッドレス運用指示により実行しておらず、VG-01〜VG-05は引き続き未合格とする。

UI E2Eでは次を確認した。

- 未許可状態で理由、設定、再確認、終了を表示
- 未許可から許可済みへの再確認遷移
- テスト時にシステム設定への外部遷移を抑止
- 権限案内からアプリを終了
- 権限済みポップアップのヘッダー、空状態、再読み込み、設定、終了を表示
- 隠れている項目、表示中の項目、表示位置を確認できない項目を分離して表示
- 操作非対応と操作失敗を、ポップアップを閉じずに通知

E2Eの初回実行ではStoryboardなしAppKitアプリのエントリーポイント不備を検出した。プロセスは起動するが`AppDelegate`が生成されない状態だったため、`NSApplication`、`AppDelegate`、イベントループを明示的に接続するエントリーポイントへ修正した。

UI E2E全回帰と実機fixtureは、利用者の作業画面を前面化しない時間帯に限って実施する。未実行項目を「合格」とは記録しない。

## Ice停止時の独立動作確認

Ice 0.11.12を一時終了し、MenuAllがIceに依存せずAccessibility APIから項目を取得・操作できるか確認した。

- Ice終了後もRectangle、QuickCopy、Cursor、Claude、ChatGPTなどの項目を継続して列挙できた。
- Claude、Google Chrome、Ollama、Kiro CLIなどの項目で`AXPress`が成功した。
- 検証後にIceを再起動し、元の利用状態へ戻した。Iceはアンインストールしていない。

この確認はAX取得・操作経路の独立性を検証したものであり、現在の検証機はMac miniのため、ノッチ裏項目に対するSP-02の証拠には含めない。また、固定署名した現在のビルドはTCCの再許可が必要なため、MenuAll UIからの最終再確認は固定署名TCC再許可待ちである。

表示管理については、Ice、Bartender等の同種アプリと同時に配置を変更すると競合するため、検出時に切り替え操作を無効化し、利用者へ理由を示す。MenuAllが競合アプリを自動終了、設定変更、アンインストールすることはしない。検証で一時終了する場合は利用者の許可を得て、終了後に元の利用状態へ戻す。

また、AX情報と取得可能なWindowServer情報だけで対象を一意に特定できない項目、固定システム項目、変更結果を再観測できない項目は、誤操作を避けるため理由付き`unsupported`とする。公開APIで保証できない対象を「すべて操作可能」とは表現しない。

## 現時点の判定

**追加検証**。

アプリ基盤、権限案内、AX列挙・元メニュー操作経路、ポップアップ、設定、従来範囲のTDDとUI E2Eは実装済み。SP-01、SP-03、SP-04は合格し、Ice終了中も列挙・元メニュー操作経路が独立して動作することを確認した。表示管理は新しいMVP範囲として実装・検証中であり、VG-01〜VG-05の合格前には完了としない。現在のMac miniにはノッチがないためSP-02の合否は判定できず、SP-05はDeveloper ID証明書と公証資格情報を使う配布検証が残る。

SP-02、SP-03、VG-01、VG-02またはVG-03が不合格の場合は、MVPの中心価値、対応対象、表示管理の提供範囲を見直す。
